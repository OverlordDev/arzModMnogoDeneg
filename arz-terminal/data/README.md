# data/ — реальные цены ArzMarket

Файлы `market_<server>.json` готовит `scripts/import_arzmarket.py`
из публичных агрегатов средних цен скрипта Arizona Market
(репозиторий `FREYM1337/forumnick`, папка `avg_price`).

## Что внутри market_<server>.json

- `buy` — средневзвешенная **скупка** (что лавки платят) за окно;
- `sell` — средневзвешенная **продажа** (что лавки просят) за окно;
- `change` — изменение средней продажи vs ~7 дней назад, %;
- `liq` — ликвидность по объёму (Высокая/Средняя/Низкая/Очень низкая);
- `conf` — уверенность 40–97 (объём + свежесть);
- `upd` — давность последнего дня с данными («сегодня», «2 дн.»);
- `history` — до 30 дневных средних продажи (для графика);
- `lastDate`, `dealsBuy`, `dealsSell`.

Окно по умолчанию — 14 дней. Позиции без сделок за 90 дней
не включаются. Дни-выбросы (средняя цена дня отличается от
взвешенной медианы более чем в 4 раза) отбрасываются.

## Обновление

```powershell
python scripts/import_arzmarket.py --server phoenix tucson --window 14
```

Скачивание идёт во временную папку, в репозиторий ложатся
только компактные `market_*.json` (~1 МБ на сервер).

Доступные серверы: yuma, vc (Vice City).

В терминале используются **только эти два сервера**, экономики
строго изолированы: связки считаются внутри сервера,
межсерверного арбитража нет (у Yuma — вирты $, у Vice City — VC$).

## История цен (дампы каждые 30 минут)

`scripts/snapshot.py` (задача планировщика Windows `ARZTerminalSnapshots`,
каждые 30 минут, `scripts/run_snapshot.bat`):

- проверяет свежие агрегаты и пишет очередной дамп (каждые 30 минут,
  даже если цифры не изменились — так видна и динамика, и простои источника);
- обновляет `data/market_<server>.json` для терминала;
- пишет компактный снапшот в `data/history/<server>/YYYYMMDD-HHMM.json`
  (`[name, buy, sell, qtyBuy, qtySell, lastDate]`) — это и есть история цен;
- ротация: полное разрешение хранится 48 часов, дальше — один снапшот
  в сутки (12:00) до 90 дней; `data/history/index.json` — манифест.

Ручной запуск: `python scripts/snapshot.py` (по умолчанию yuma + vc).

## Ограничения (читать обязательно)

1. Это **агрегаты**, а не live-лавки: дневные средние, лаг 1–3 дня.
2. Данные краудсорсные — их загружают игроки со скриптом;
   покрытие смещено в сторону активных торговцев.
3. `buy`/`sell` — средние по всем лавкам сервера, а не лучшая
   цена конкретной лавки. Конкретную дешёвую лавку всё равно
   искать в игре.
4. Малоликвидные позиции (conf < 60, «Очень низкая») — ориентир,
   а не цена сделки.
5. Терминал показывает файл того сервера, который загружен
   (см. «Сервер данных» в Market). Для серверов без файла —
   демо-данные.
