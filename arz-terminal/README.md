# ARZ Terminal — визуальный каркас

Минималистичный прототип системы фарма, перекупа и аналитики рынка Arizona RP.

## Как открыть

Вариант 1 — просто открыть `index.html` в браузере.

Вариант 2 — локальный сервер (удобнее для проверки на телефоне):

```powershell
cd C:\Users\negrozoido\Desktop\arzModMnogoDeneg\arz-terminal
python -m http.server 8080
```

Открыть: `http://localhost:8080/`

Для мобильного вида: `http://localhost:8080/preview-mobile.html` — страница с iframe 390×844.

## Что внутри

| Раздел | Что показывает |

| **Arbitrage** | Карточки связок и таблица возможностей |
| **Farming** | План на день, распределение капитала, активности с прибылью в час |
| **Business Lab** | Сравнение бизнесов и живой калькулятор окупаемости |
| **Craft Lab** | Рецепты, себестоимость, шанс успеха, expected value |
| **Auctions** | Лоты, таймеры, max-ставка, история hammer price |
| **Portfolio** | Активы, P&L, аллокация, динамика капитала |
| **Deals** | Kanban-воронка перекупа |
| **Alerts** | Правила, переключатели, превью Telegram-бота |
| **Items** | База всех предметов вики (8 756 шт.): поиск, категории, редкость, ссылки |
| **Jobs** | Калькулятор работ: чистыми в час, расходы, бонусы. Аксы — выпадающий список только по выбранной работе (68 позиций с подсказками) |
| **База предметов (исходник)** | `research/arz_jobs/items_catalog.json` — 8 756 предметов вики (имена, категории, редкость, ссылки), `scripts/scrape_items.py` + `categorize_items.py` для обновления |
| **Deposit** | Депозит: уровни 0–5, проценты по VIP, бонусы/штрафы, калькулятор дохода |
| **Данные работ** | `data/jobs.json` (28 работ, медианы из 125 замеров) + `data/job_items.json` (аренда, сиропы, бафы с подсказками) |
| **Данные депозита** | `data/deposit.json` (делители VIP, уровни, бонусы, штрафы, примеры из вики) |
| **History** | Дампы цен каждые 30 мин, графики скупки/продажи по предмету |
| **Meta** | Гайды, тир-лист, патчноуты |
| **Settings** | Сервер, валюта, интерфейс, данные |

## Дизайн

- Тёмно-серая база: `#0e0f11`, панели `#181a1e`.
- Белые акценты: primary-кнопки, активный пункт меню, переключатели, ключевые бейджи.
- Цвета статусов: зелёный — прибыль/низкий риск, красный — убыток/высокий риск, янтарный — средний риск.
- Шрифты: Inter/system + моноширинные цифры.
- Без внешних библиотек и иконок — всё на SVG и CSS.

## Реальные данные (ArzMarket)

Market, связки на Dashboard/Arbitrage и карточка предмета уже умеют
подтягивать **реальные средние цены лавок**:

- источник — публичные агрегаты скрипта Arizona Market
  (`github.com/FREYM1337/forumnick`, папка `avg_price`, файлы
  `info_users_buy_<server>.json` / `info_users_sell_<server>.json`);
- `buy` = скупка (что лавки платят), `sell` = продажа (что просят);
- обновление: `python scripts/import_arzmarket.py --server yuma vc`;
- готовые файлы лежат в `data/` (`market_yuma.json` — 2 376 позиций,
  `market_vc.json` — 3 396 позиций, свежесть — 16.11.2026);
- **серверы: только Yuma и Vice City**, экономики изолированы
  (межсерверного арбитража нет: у Yuma — $, у Vice City — VC$);
- загрузчик — `js/realmarket.js`: подменяет мок-данные, строит
  внутрисерверные связки (с фильтрами от мусора:
  объём с нужной стороны ≥ 30, стабильность цен, одинаковый порядок цен);
- **история цен**: `scripts/snapshot.py` + задача планировщика
  `ARZTerminalSnapshots` (каждые 30 минут) пишут дампы
  в `data/history/<server>/` (всегда, даже без изменений),
  ротация 48ч полно + 90 дней посуточно;
  раздел **History** в терминале строит по дампам графики
  скупки/продажи любого предмета.
- если файла сервера нет — остаются демо-данные, в Market видно
  «Сервер данных».

Подробности и ограничения — в `data/README.md`.

## Важно

Это **визуальный каркас c реальными рыночными данными**.
Демо-остатки: KPI/портфель/сделки/ивенты/аукционы — заглушки. Здесь нет:
- бэкенда и базы данных;
- live-ленты лавок (только дневные агрегаты ArzMarket);
- авторизации;
- Telegram-бота.
