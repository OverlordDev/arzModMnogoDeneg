# ARZ Terminal — визуальный каркас

Минималистичный прототип системы фарма, перекупа и аналитики рынка Arizona RP.

## Как открыть

Вариант 1 — просто открыть `index.html` в браузере.

Вариант 2 — локальный сервер (удобнее для проверки на телефоне):

```powershell
cd C:\Users\negrozoido\Desktop\arzModMnogoDeneg\arz-terminal
python -m http.server 8080
```

Открыть: `http://localhost:8080/`

Вариант 3 — Node-сервер (для VPS, ноль зависимостей):

```bash
node server.js          # PORT=3000 по умолчанию
```

Проверка: `http://localhost:3000/api/health` → `{"ok":true,...}`.
Деплой на VPS для двоих — см. `deploy/DEPLOY-VPS.md`
(systemd-сервис + cron дампов каждые 30 минут, `deploy/vps-setup.sh`).

Для мобильного вида: `http://localhost:8080/preview-mobile.html` — страница с iframe 390×844.

## Игрок из игры (локально)

Инвентарь, деньги, сытость и розыск читаются из самой игры. Arizona присылает
их клиенту CEF-событиями (пакет 220), скрипт MoonLoader их **только читает**:

1. `game/arz_export.lua` → в `<Arizona>\bin\arizona\moonloader\`. Пишет только
   белый список событий в `arz_player_events.log` (авторизация и токены не пишутся).
   Ничего не отправляет серверу и в сеть, пакеты не перехватывает.
2. Зайти на сервер: полный инвентарь приходит **один раз при входе**, дальше —
   изменения слотов. Без этой загрузки сайт помечает инвентарь «неполно».
3. `node server.js` на этом же ПК: сервер следит за файлом и толкает изменения
   в браузер по SSE (`/api/player/stream`, ~0,15 с), запасной опрос — `/api/player`.

Стоимость — по ценам ArzMarket (`data/market_*.json`): скупка / продажа / середина.
Предметы без рыночной цены в сумму не входят и перечисляются отдельно.
ID предметов → названия: `data/items_names.json` (из репо ArzMarket).

Приватность: `/api/player*` отдаются только с loopback-адреса и Host `localhost`,
без CORS (иначе любая открытая вкладка могла бы прочитать инвентарь). На VPS/статике
данных игрока нет намеренно. Файл игрока: `ARZ_EVENTS_FILE`, интервал
страховочного разбора: `ARZ_PLAYER_PARSE_MS` (по умолчанию 30000).

**Заработок в час** считается по изменениям денег (`game/arz_stats.js`): приход,
расход и чистыми за 15 минут / час / сессию. Приход — любые поступления, а не
только работа; если в окне доминирует одно крупное поступление, оно помечается
«разово». **История капитала** (деньги + оценка инвентаря) пишется раз в минуту при
изменениях в `local/player_history.jsonl` — это личные данные, папка в `.gitignore`
и не должна оказываться в `data/` (её автоматически пушит планировщик).
Тесты: `npm test` (синтетические данные, реальные логи в репо не кладём).

`game/arz_recon.lua` — разведчик (логирует имена CEF-событий, чтобы находить новые),
`game/arz_parser.js` — события → состояние, `game/arz_value.js` — оценка и советы.

## Реальные данные (ArzMarket)

Market, связки на Dashboard/Arbitrage и карточка предмета уже умеют
подтягивать **реальные средние цены лавок**:

- источник — публичные агрегаты скрипта Arizona Market
  (`github.com/FREYM1337/forumnick`, папка `avg_price`, файлы
  `info_users_buy_<server>.json` / `info_users_sell_<server>.json`);
- `buy` = скупка (что лавки платят), `sell` = продажа (что просят);
- обновление: `python scripts/import_arzmarket.py --server yuma vc`;
- готовые файлы лежат в `data/` (`market_yuma.json` — 2 376 позиций,
  `market_vc.json` — 3 396 позиций, свежесть — 16.11.2026);
- **серверы: только Yuma и Vice City**, экономики изолированы
  (межсерверного арбитража нет: у Yuma — $, у Vice City — VC$);
- загрузчик — `js/realmarket.js`: подменяет мок-данные, строит
  внутрисерверные связки (с фильтрами от мусора:
  объём с нужной стороны ≥ 30, стабильность цен, одинаковый порядок цен);
- **история цен**: `scripts/snapshot.py` + задача планировщика
  `ARZTerminalSnapshots` (каждые 30 минут) пишут дампы
  в `data/history/<server>/` (всегда, даже без изменений)
  и пушат в main — Render сам передеплоит сайт;
  ротация 48ч полно + 90 дней посуточно;
  раздел **History** в терминале строит по дампам графики
  скупки/продажи любого предмета.
- если файла сервера нет — остаются демо-данные, в Market видно
  «Сервер данных».

Подробности и ограничения — в `data/README.md`.

## Важно

Это **визуальный каркас c реальными рыночными данными**.
