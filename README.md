## Как это собиралось

1. `yt-dlp` выгрузил список всех 317 видео канала.
2. Отобраны 87 роликов за последние 4 года, из них 62 — про Arizona RP / Arizona V.
3. Для каждого скачаны авто-субтитры (`ru`, при отсутствии — `en`).
4. Скрипт `scripts/vtt_to_txt.py` убрал таймкоды, теги и «бегущие» дубли.
5. Каждое видео разобрано отдельным агентом по единому шаблону.
6. Ключевые обновления 2025–2026 сверены с официальными патчноутами.
7. Экономика сверена с вики, гайдами и обзорами.

## Важные оговорки

- **Arizona RP ≠ Rodina RP.** Это разные проекты с разной экономикой. Rodina RP в обзор не входит.
- **Arizona V (GTA 5, RAGE:MP) закрыта 01.09.2026** после прекращения работы RAGE:MP. Прогресс и донат не переносятся.
- **Цифры зависят от сервера.** На Arizona RP каждый SA-MP-сервер — отдельный «штат» со своей экономикой.
- **Авто-субтитры искажают имена и числа.** В спорных местах в главном документе стоят пометки «примерно» / «не подтверждено».
- Полные транскрипты и заметки лежат в `research/` — можно проверить любой тезис.
