# 📦 Криптосумки и кошелек

Встречайте — Крипто‑сумки! Это не просто аксессуар для хранения NFT‑контейнеров: помимо освобождения места в инвентаре, сумка даёт полезные игровые бонусы.

Ключевые особенности:
- 

Доступно 4 уровня Крипто‑сумок, со своими бонусами и вместительностью;
- 

Возможность улучшения через крафт — развивайте свою сумку, чтобы получать больше бонусов;
- 

Приобрести сумки можно в игровом магазине.

Обновление системы «Кошелёк»

Мы усовершенствовали систему «Кошелёк» для вашего комфорта:
- 

Увеличено количество ячеек — теперь вы можете хранить больше предметов;
- 

Сохранение состояния: открытый кошелёк и аналогичные предметы остаются на экране после закрытия инвентаря;

Фиксация положения: расположение кошелька фиксируется в выбранной вами точке экрана — больше не нужно перетаскивать его каждый раз.
